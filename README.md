 🌿 Git Practice Laboratory
Welcome to my dedicated Git practice sandbox! This repository is a hands-on lab designed to master advanced Git version control, branching strategies, collaborative workflows, and disaster recovery commands.
---
## 🛠️ Key Workflows Practiced
*   **Core Fundamentals**: Local repository initialization (`git init`), staging files, checking statuses, and crafting descriptive commits.
*   **Branching Strategy**: Creating, switching, deleting, and renaming branches safely (`git checkout -b`, `git switch`).
*   **Remote Integration**: Syncing local repositories with remote origins and tracking upstreams (`git remote`, `git push`, `git pull`).
*   **Advanced Merging & History**: Fast-forward merges, commit merges, squashing commits, and rebasing branches to maintain a clean linear commit graph.
*   **Stash & Workspace Management**: Saving temporary progress safely (`git stash`) and cherry-picking isolated commits across branches.
*   **Undoing Changes Safely**: Backtracking using `git reset (--soft, --mixed, --hard)` and reverting public commits safely using `git revert`.
